# MediteraniAPP

A fast, simple meal planning app for families and couples following a Mediterranean diet.

## What it does

When you're hungry and don't know what to cook, open the app and get a smart meal suggestion in under 30 seconds. The app avoids repeating meals from the last 7 days, respects occasional meals (10-day rule), and lets your team track shared meal history.

**Core features:**
- Instant meal suggestion on app open (no taps needed)
- 7-day no-repeat rule enforced automatically
- Shared team menus for families and couples
- Create and edit meals directly in the app
- Shopping list generation by ingredient category
- Supports iOS, Android, and Web

## Tech stack

- **Frontend:** React Native (Expo)
- **Backend:** Firebase (Auth, Firestore, Hosting)
- **IDE:** VS Code
- **Testing:** iOS Simulator

## Getting started

See [dev-guide.md](dev-guide.md) for full environment setup instructions (estimated ~2-3 hours first time).

```bash
# Install dependencies
npm install

# Start development server
npx expo start
```
